# Data Structures and Algorithms (DSA)

A collection of C++ implementations covering fundamental data structures and classic algorithms.

## Topics

### Core Data Structures

- **Arrays & Vectors** - Dynamic arrays and vector operations
- **Linked Lists** - Singly and doubly linked list implementations
- **Stacks** - LIFO data structure using STL
- **Heaps** - Priority queues and custom comparators
- **Binary Trees** - Tree structures and traversals

### Graph Algorithms

- **Graph Representations** - Adjacency list, matrix, and edge list
- **Traversals** - BFS, DFS (1D and 2D grids)
- **Shortest Paths** - Dijkstra, Bellman-Ford, Floyd-Warshall
- **Union-Find/DSU** - Disjoint set implementations
- **Graph Problems** - Knight moves, maze solving, road construction

### Advanced Topics

- **Dynamic Programming** - Knapsack, Fibonacci, subset sum, partition problems
- **Math & Number Theory** - GCD, LCM calculations
- **Memory Management** - Dynamic allocation and deallocation

## Usage

Each file is a standalone C++ program demonstrating specific concepts. Compile and run with:

```
g++ filename.cpp -o output
./output
```

## Language

C++
